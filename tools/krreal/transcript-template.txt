# Transcription rules (KR-Real v1)
# - Copy all the text on the page, including running heads, body text, footnotes and page numbers.
# - Write each line of text in the photo on its own line, in reading order.
# - Copy spacing, punctuation, Hanja, Latin letters and digits exactly as printed. Keep hyphens at line ends too.
# - Write one table row per line, with a single tab between cells.
# - Write formulas as [[formula]], and text inside figures and stamps as [[figure]].
# - Write [[?]] for each character you cannot read.
# - Zoom the photo to 100% and compare it line by line. If there is an OCR draft, check every character against the photo and correct it.
# - After the first pass, change status to transcribed and put your name in transcribed_by.
# - After a second person has compared it again, change status to checked and put their name in checked_by.
# - Save as UTF-8 (NFC). Do not delete the --- line below.
